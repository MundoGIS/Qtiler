VectorTiles plugin

Create MBTiles vector tiles from QGIS projects and expose TileJSON + MVT URLs.

Plugin README

VectorTiles builds and serves vector tiles for Qtiler projects, including on-demand generation and style endpoints.

  • Generation: creates MBTiles from selected vector layers and zoom ranges.
  • Serving: exposes tile endpoint, TileJSON, and style JSON for GIS and web clients.
  • On-demand: missing tiles can be generated from requested z/x/y to reduce prebuild time.
  • Operations: monitor jobs queue, retry/cancel tasks, delete cache, and copy style links.
  • Security: combines with QtilerAuth to protect project access using session or api_key.
